# Phone remote directions

Mechanism: one approved phone moves the native TV browser pointer and edits
eligible fields, without accounts or a companion installation. Audience: a
person looking between phone and television, prioritizing touchpad browsing.
The routine page is a long dark button stack; its predictable opposite is a
novelty remote-control illustration. Neither is a candidate.

All candidates retain standard web controls, compact live page identity, a
primary touchpad, reachable quick actions and separate typing/tabs views.
Dark scene is inherited from the established local-remote product brief;
night-time couch use is a documented inference, not a new confirmed claim.

1. Evening velvet: cinema upholstery; warm graphite, dusty lavender, ivory,
   system UI type. The pad owns quiet space; a restrained pressed-state tint
   makes gesture contact legible. Familiar evening browsing without screen glare.
2. Pocket paperback: a well-made pocket book's compact hierarchy; graphite,
   muted jade, warm white, system UI type. Compact identity and clear chapter-like
   task navigation leave the pad uninterrupted. Reading clarity in little space.
3. Transit night map: everyday wayfinding precision; ink navy, cornflower blue,
   cool white, system UI type. A continuous active-task indicator aligns the
   control deck; labels stay literal rather than pretending to be transit routes.
4. Cinema programme: short, ordered information in film programmes; charcoal,
   muted coral, ivory, system UI type. Page title/origin leads a quiet work area;
   typography separates frequent controls from occasional browser tasks.
5. Record sleeve: a record jacket's confident color grouping; aubergine,
   soft violet, pale ink, system UI type. Pad and click affordance form one clear
   region; no invented album covers or decorative playback claims.
6. Gallery afterhours: room-scale negative space and clear wayfinding; deep blue,
   dusty teal, off-white, system UI type. Compact header/identity, a large plain
   pad, and an anchored navigation bar. Gestures are explained where used.
7. Library cloth: bookcloth's durable warm neutrals; deep forest, moss, oatmeal,
   system UI type. Strong tab rhythm and a flat, tactile-looking pad without
   ornamental texture. Connection state has its own readable line.

Operate mode: these worlds provide type/palette/density/one signature, never
invent control protocols, overwrite task structure or add tool-themed costumes.
