# Phone field Enter

Mode: Operate. Ordinary local extension of the bundled phone companion; preserve
PRODUCT.md, DESIGN.md and design.json. Code-led; no comp, seed or new world.

THESIS: Finish typing and invoke the selected TV field directly, without returning
to the pointer or finding a webpage button.

INCUMBENT: The existing After hours phone system, Type task, stable textarea,
teal primary controls and quieter auxiliary actions. Keep native field/document
ownership and composition feedback.

FIRST VIEWPORT: In Type, one full-width primary action immediately below the
editor. Its native action is Enter, Search, Go, Send or Done. The existing Delete
and Finish composition controls remain secondary beneath it. Use existing button
tokens, typography, radius and focus treatment, including narrow phone reflow.

STATES: Explicit Type/editor interaction first hands typing from the TV keyboard
to the phone, keeping webpage focus and text intact. Until acknowledged, the
editor is read-only and the native action disabled. Finish composition is an
explicit alternative when the TV still owns a candidate. Leaving Type, background,
physical TV input or field/context loss returns control without automatic reclaim.
No field/password/private/native-owner/disconnected states disable the action.
Candidate composition cannot submit. Pending text is acknowledged before Enter;
the editor retains focus and becomes read-only, the action disables, and short
status copy explains delivery. Target changes/failure discard the intent. Native
Enter preserves form validation, site handlers and multiline newline behavior.

SIGNATURE: One visible native field action, mirrored to the phone keyboard hint.
No inferred form/search intent, hidden selector click or success claim.

QUALITY BAR: Action findable beside typing; narrow portrait and landscape fit;
keyboard focus and contrast follow incumbent; latest Unicode text submits once;
composition and target changes never send a stale action. Bundled host regression
and paired TV/phone emulator APK evidence are distinct. Hardware/Safari remain
deferred by the user.
